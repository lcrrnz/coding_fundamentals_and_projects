# Pseudocoding & Terminal Basics

## Overview
Introduction to algorithm planning with pseudocode and file and process management from the command line.

## Key Concepts

### Pseudocode
- Sequential algorithms with defined start and end
- Variable definition with `Definir`
- Conditions: `Si ... Sino ... FinSi`, including nested logic
- Loops: `Mientras ... FinMientras`

### Terminal (Windows PowerShell)
- File and folder management: `mkdir`, `New-Item`, `Move-Item`, `Rename-Item`, `Remove-Item`
- File content: `Set-Content`, `Get-Content`
- Process management: `Get-Process`, `Stop-Process`
- System utilities: `Get-Date`, `ping`
